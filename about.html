About Hunar

Hunar (skill) is a free learning academy built to replace paid Skill Up / Codiea-style programs with structured curricula that use only legal, free resources.

What we offer

Career tracks mapped from the Skill Up Prospectus 2026 and rebuilt with free materials:

  • Web Development Foundations
  • UI/UX Design Bootcamp
  • Graphics Design Foundations (includes game/store screenshot design)
  • Digital Marketing Foundations
  • SEO Specialist Path
  • Content Writing
  • App Store Optimization (ASO)
  • Unity 3D Game Development
  • 3D Modeling with Blender
  • Video Editing (DaVinci Resolve Free)
  • Flutter App Development
  • WordPress Development
  • Lead Generation

How each track is built

  • Official documentation (MDN, React, Flutter, Dart, Unity, Blender, Google Search Central, WordPress Learn…)
  • Free courses (freeCodeCamp, Google Digital Garage, HubSpot Academy, Unity Learn)
  • Free tools (Figma, Photopea, Inkscape, DaVinci Resolve, GitHub Pages, Search Console)
  • Educator YouTube series that are freely published

Resource policy

We never recommend pirated courses, cracked software, leaked paid content, or unauthorized downloads. If a resource is not free and legal, it does not appear here.

How progress works

Progress is stored in your browser (localStorage). No account, no tracking server. Clear site data resets progress. Export a JSON backup from the Dashboard anytime.

Languages

UI chrome and lesson fields support English with Roman Urdu strings in the curriculum data. Use the language toggle in the header where implemented. Full page-level Roman Urdu is expanding over time.
