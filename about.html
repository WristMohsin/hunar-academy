About Hunar

Hunar (ہنر — skill) is a free learning academy built to replace paid Skill Up / Codiea-style programs with structured curricula that use only legal, free resources.

What we map

From the Skill Up Prospectus 2026 we extracted every major track — Web Development, UI/UX, Graphics, Content Writing, Digital Marketing, SEO, ASO, Unity 3D, 3D Modeling (Blender), Video Editing — and rebuilt each as a module/lesson path with:

  • Official documentation (MDN, React, Laravel, Unity, Blender, Google Search Central…)
  • Free courses (freeCodeCamp, Google Digital Garage, HubSpot Academy, Unity Learn, Coursera audit where available)
  • Free tools (Figma, Photopea, Inkscape, DaVinci Resolve, GitHub Pages, Search Console)
  • Educator YouTube series that are freely published

Resource policy

We never recommend pirated courses, cracked software, leaked paid content, or unauthorized downloads. If a resource is not free and legal, it does not appear here.

How progress works

Progress is stored in your browser (localStorage). No account, no tracking server. Clear site data resets progress.

Toggle EN / Roman Urdu from the header. Lesson explanations and UI strings switch together.
